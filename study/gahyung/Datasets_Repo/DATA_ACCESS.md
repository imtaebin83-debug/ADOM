## Access Rule

- 팀원 계정에만 접근 권한을 부여합니다.
- 공개 링크는 사용하지 않습니다.
- 원본 데이터셋의 재배포 조건을 확인합니다.
- 라이선스가 불명확하면 masks-only package를 사용합니다.
- 데이터 변경 시 같은 파일을 덮어쓰지 않고 버전을 올립니다.
